# A4 多语言框架（i18n）设计

> 范围：i18n 地基 + 8 语种框架 + 壳层文案抽取（非全量）。
> 落点：设置页「语言」卡（A15）。commit 见 git log（A4）。

## 1. 为什么是这个范围

桌面端早已装好 `i18next` + `react-i18next`，但全仓库**没有任何 i18n 实例初始化、没有 locale 资源文件**——
`useTranslationSync` 名字像国际化，实际同步的是「翻译开关标志」到内嵌网页，跟 UI 文案无关。

清单写的是「i18n（zh-CN / en 起，8 语种框架）」。全量抽取 84 个含中文的渲染层文件是一次性不可 review 的大改动，
风险高。因此本笔只做**框架 + 壳层**（设置/导航/登录/日志中心/标题栏/占位页），证明链路通、可逐文件 review，
其余 40+ 页面组件作为后续增量（每抽一批单独 commit）。

## 2. 架构

```
主进程 settings.ts           渲染层
─────────────────          ───────────────────────────────────
AppSettings.language  ──IPC settings:get/set/changed──►  useLanguage()
   (落盘 JSON)                                          │
                                                          ▼
                                              i18n.changeLanguage()
                                                          │
                                              i18n 实例 (i18next + react-i18next)
                                                          │
                                              resources: { 'zh-CN', en }
                                                          │
                                              useTranslation() → t('namespace.key')
```

- **真值源在主进程**：`AppSettings.language` 由主进程落盘（`scrm-settings.json`），渲染层只是客户端。
  与 `theme` / `badgeEnabled` 同一分工，不另立一套持久化。
- **首帧前初始化**：`main.tsx` 在 `createRoot` 之前 `await initI18n()`，读回持久语言当 `lng`。
  资源是打包进来的（非 fetch），`init` 后 `t()` 立即可用，不会闪错语种。
- **即时切换**：设置页选语种 → `useLanguage().setLanguage` 先切运行时语言、再 `settings:set` 落盘。
  主进程广播 `settings:changed`，其他订阅者同步。

## 3. 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 语种清单放哪 | `@shared/i18n.ts` | 主进程校验 + 渲染层切换器共用一份，避免「一个认一个不认」 |
| 完整译文 | 先 zh-CN / en 两份 | 其余 6 种列在 `SUPPORTED_LOCALES`，未译回退 `fallbackLng`（zh-CN） |
| 校验落盘值 | `isLocaleCode()` 白名单 | 只认清单里的代码，任意字符串不写进设置文件 |
| 键结构 | `namespace.key`（点分隔） | react-i18next 默认 `keySeparator`，嵌套对象即命名空间 |
| 漏译表现 | `returnNull: false` | 取不到的键返回 key 本身，界面上立刻看出「这句没翻」 |
| en 与 zh-CN 对齐 | `DeepString<typeof zhCN>` 标注 | 编译期保证键完全一致，漏键/多键/层级错直接 typecheck 失败 |

## 5. 给后续增量的约定

**加一句壳层文案**：在 `zh-CN.ts` 加键 → `en.ts` 补译文 → 组件 `const { t } = useTranslation()` 用 `t('scope.key')`。
**加一种语种**：在 `SUPPORTED_LOCALES` 加 `{ code, label }`，复制 `en.ts` 为 `<code>.ts` 译满，注册进 `i18n/index.ts` 的 `resources`。
**全量抽取剩余 40+ 页面**：按模块分批，每批独立 commit（沿用单功能单 commit 纪律）。
