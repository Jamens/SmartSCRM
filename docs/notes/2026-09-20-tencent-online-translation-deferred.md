# 腾讯线上翻译暂缓说明

日期：2026-09-20 · 关联：`docs/superpowers/specs/2026-09-19-translation-center-design.md` §9

## 决定

腾讯（TMT）线上翻译**暂缓**，不再作为当前验收项：代码与入口已全部就绪，只差真实密钥联调。
用户决定先把精力投入 P6，等需要时再回来配 key。

## 已就绪的部分（无需重做）

- 后端适配器 `tencent`：TC3-HMAC-SHA256 签名 + `TextTranslate`，端点规格已探针核实；单测通过。
- 渠道路由：线路 7 → provider `tencent`；未配密钥或调用失败 → 回退模拟引擎并标 `degraded=true`（结果不入缓存）。
- 凭据 API：写入后仅返回 `hasSecret` 掩码，密钥不回显、不下发渲染层/注入层。
- 翻译中心「密钥配置」卡片：填 SecretId/SecretKey/region 即存，「测试」按钮给 `可用 · Xms` / `不可用：原因`。

## 未完成的部分（暂缓的就是这一格）

真实密钥下的线上链路 E2E 未跑。在此之前，线路 7 的口径保持「线上链路未实跑」。

## 恢复步骤（将来要做时）

1. 翻译中心 → 密钥配置 → 腾讯云 TMT，填 SecretId / SecretKey / region，保存；
2. 点「测试」，看到 `可用 · Xms`；
3. 线路切到 7，在翻译试用里跑一条**含空格的跨语种**译文（如 zh→en），确认 `degraded=false`、再跑一次命中缓存；
4. 回填规格 §9.5，去掉线路 7 的「线上链路未实跑」标记。

## 现状对照（同口径）

- 百度：已完成上述全流程联调（2026-09-19，`可用 · 262ms` / 线上译文 / 缓存命中）。
- 腾讯：停在第 1 步之前，其余完全一致。
